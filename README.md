# Robot Manager 🤖

A simple Python program that monitors robot battery levels and gives a battery status for each robot.

## Features

- Stores multiple robots using a list of dictionaries
- Checks battery levels
- Uses `if`, `elif`, and `else` for decision-making
- Displays the status of each robot

## Technologies Used

- Python 3
- Linux
- Git
- GitHub

## Example

The program checks each robot's battery and displays:
- Fully Ready
- Ready
- Needs Charging
- Critical

## How to Run

```bash
python3 robot_manager.py
